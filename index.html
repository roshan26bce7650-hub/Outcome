GOOD TO KNOW

Clear odds.
Clear limits.

Prediction tools are only as useful as the data behind them.

Do I need to create an account?＋

No. The public prediction interface is available without registration or login.

Does it support every game in the directory?＋

The directory is a broad game catalogue. Meaningful predictions require a trained model and comparable historical features for the selected game. Unknown game categories can be included in a dataset, but model performance must be checked per category.

Are predictions guaranteed to be correct?＋

No. Probabilities express the model's estimate, not certainty. Accuracy varies with the data, feature quality, competition and changing conditions.

How do I improve model quality?＋

Use clean, representative historical records, features known before each match, enough examples for each outcome, and a time-based test split when predicting future events.
